# Ustaad AI - Science Tutor

Ustaad AI is a Streamlit-based AI science tutor for Pakistani students from Grade 9 to Grade 12. It helps students understand science concepts in simple language using examples, step-by-step explanations, and real-life applications.

## Features

- AI-powered science tutor
- Supports Grade 9, 10, 11, and 12
- Subjects include Physics, Chemistry, and Biology
- Topic-based learning
- Answers in:
  - Roman Urdu
  - English
  - Urdu
- Text question support
- Passage explanation support
- Image upload support for diagrams or problem statements
- Chat-style interface
- Uses Google Gemini API

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- Requests
- PyPDF2
- python-dotenv
